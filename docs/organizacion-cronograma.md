# Procedimiento de Organización de Pruebas

Este documento detalla el procedimiento operativo para la organización y publicación del cronograma de pruebas de las Olimpiadas Científicas de la FNI
## Pasos Operativos

El proceso para organizar el cronograma de evaluaciones consta de los siguientes pasos:

1. **Registro inicial:** El Coordinador registra las fechas, sedes y aulas disponibles para las evaluaciones.
2. **Asignación de pruebas:** Se asocian las pruebas específicas con sus respectivas disciplinas y etapas de la competencia.
3. **Verificación de conflictos:** El sistema verifica automáticamente que no existan conflictos (como cruces de horarios o aulas sobreasignadas).
4. **Publicación oficial:** Una vez validado, se publica el cronograma autorizado en la plataforma para el conocimiento de tutores y estudiantes.
5. **Gestión de cambios:** Se comunican oficialmente las modificaciones posteriores (como postergaciones o cambios de aula), utilizando el módulo de avisos de la plataforma.
